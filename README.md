# الكورنيش اللانهائي — هيكل المجلد

```
index.html          الصفحة (الواجهة + ترتيب تحميل الملفات)
css/                التنسيقات
js/game.js          كود اللعبة كله
js/drive-physics.js فيزياء القيادة الواقعية (إطارات، توزيع وزن، تعليق) — رياضيات فقط بدون three.js
js/drive-game.js    ربط الفيزياء باللعبة + آثار الإطارات ودخانها وصوت الصرير وكاميرا المطاردة
js/gfx-plus.js      الظلال، الانعكاسات الحية، التوهج HDR وتصحيح الألوان، لمعان الأسفلت، أشجار النخيل
js/sky-plus.js      السماء: غلاف جوي، شمس وقمر، طبقة غيوم مضاءة، درب التبانة، نجوم متلألئة
js/city-plus.js     المباني: غرف حقيقية خلف النوافذ (Interior mapping)، زجاج بانعكاس Fresnel، تنوع وتعتيق الواجهات
js/bike.js          فيزياء الموتسيكل (ميلان/عجلة خلفية/فرامل) + الراكب + الكاميرا
js/loading.js       شاشة التحميل
js/car-menu.js      بيبني أزرار اختيار السيارات تلقائياً
models/lancer.js    موديل اللانسر (السيارة الأساسية)
cars/kia/           سيارة: config.js (الإعدادات) + model.js (الموديل)
cars/lada/          سيارة: config.js + model.js
cars/yamaha/        موتسيكل ياماها MT-09 SP (config.js فيه type:"bike")
traffic/            موديلات سيارات المرور (AI)
```

شغّل اللعبة بفتح `index.html` مباشرة (محتاج إنترنت لمكتبات three.js).

## إضافة سيارة جديدة (مثلاً bmw)

1. اعمل مجلد `cars/bmw/`.
2. `cars/bmw/model.js` — ملف الموديل (GLB مضغوط gzip ومشفّر Z85):
   `(window.CAR_PACK = window.CAR_PACK || {}).bmw = {n: حجم_الـgzip_بالبايت, z: '...'};`
3. `cars/bmw/config.js` — انسخ `cars/kia/config.js` وغيّر الاسم `kia` إلى `bmw`،
   وعدّل القيم (eye/mirrors/spots...) والسطر الأخير (الأيقونة والاسم اللي يظهر في القائمة).
4. أضف السطرين في `index.html` قبل `js/car-menu.js`:
   ```html
   <script src="cars/bmw/config.js"></script>
   <script src="cars/bmw/model.js"></script>
   ```
   وكده الزر بيظهر في القائمة لوحده.

> موديل الـGLB لازم يكون فيه عقد العجلات `WHEEL_FL / WHEEL_FR / WHEEL_RL / WHEEL_RR`
> والخامة `Paint_Body` زي كيا ولادا.

## سيارات المرور
كل سيارة مرور ملف في `traffic/` بيسجّل نفسه في `window.TRAFFIC_PACK`،
وتعريفها (الاسم وطول الـgzip) في `js/game.js` عند `TRAFFIC_GZIP_BYTE_LENGTHS` و`TRAFFIC_ASSETS`.

## الموتسيكل
أي موديل بـ `type:"bike"` في config.js بيشتغل بفيزياء الموتسيكل. الموديل لازم يحتوي عقد: steer, fork_lower, wheel_f, wheel_r, swingarm, grip_l, grip_r (انظر cars/yamaha).
التحكم: A/D ميلان وتوجيه، W غاز، S فرامل أمامية، المسافة فرامل خلفية. لا يوجد رجوع للخلف (زي الموتسيكل الحقيقي).

## فيزياء القيادة (بأسلوب GTA V)
`js/drive-physics.js` فيه نموذج إطارات حقيقي بدل النموذج الـ Arcade القديم:
- كل إطار يعطي قوة حسب زاوية انزلاقه (منحنى شبيه بـ Pacejka): التماسك يزيد ثم يبلغ الذروة ثم ينزل لاحتكاك الانزلاق.
- دائرة الاحتكاك: البنزين والفرامل بياكلوا من تماسك اللف ← انزلاق الخلفية مع البنزين (Power oversteer)، ودوران العجلات.
- انتقال الوزن أمام/خلف وعزم القصور الذاتي للدوران، وتعليق بنوابض (ميلان الجسم، غطس المقدمة عند الفرملة، اهتزاز).
- فرامل اليد (المسافة) تقفل العجلات الخلفية ← لفة 180° أو دريفت. البنزين + الفرامل والسيارة واقفة = Burnout.
- مساعدات خفيفة زي GTA: قفل توجيه حسب السرعة، توجيه عكسي تلقائي خفيف، مانع دوران، ABS و EBD.
- كل سيارة لها بيانات خاصة في جدول `CARS` (اللانسر دفع رباعي متوازن، الكيا SUV أثقل وتميل أكثر، اللادا دفع خلفي وخفيفة).
  أهم القيم: `mu` التماسك، `muR` تماسك الخلفية مقارنة بالأمامية (أعلى = انزلاق أقل)، `frontBias` نسبة الدفع للأمام (0 = دفع خلفي)،
  `rollK`/`pitchK` ميلان الجسم، `assist` قوة مانع الدوران، `trackK` قوة تثبيت السيارة على مسار التوجيه (أعلى = انزلاق أقل).
  `steerRateHi`/`steerReturn` سرعة لفّ الدركسيون ورجوعه للمنتصف (أعلى = تغيير حارة أسرع)، `latK` كبح الانزلاق الجانبي عند تغيير الاتجاه.
  `hiGrip`/`hiInertia`/`hiSteer` حدّة السيارة في السرعات العالية (تماسك إضافي، دوران أخف، دركسيون أسرع) تبدأ من 60 كم/س وتكتمل عند 120 كم/س.

## الجرافيك
`js/gfx-plus.js` يتبع إعداد الجودة (تلقائي/عالية/متوسطة/منخفضة) ويمكن تعديله من الإعدادات ← الرسوميات ← «الإضاءة والانعكاسات»:
- ظلال شمس واقعية ناعمة تتبع السيارة، وظل تلامس ناعم تحت كل سيارة.
- انعكاس حي (Cube map) للطريق والمباني والسماء والأضواء والسيارات الأخرى على طلاء وزجاج وكروم السيارات.
- توهج HDR للأضواء والشمس ولمعان البحر، وتصحيح ألوان لكل وقت/طقس، ولمعان الأسفلت الجاف عند الزوايا المنخفضة.
- نخيل على رصيفي الكورنيش يتحرك مع الريح ويلقي ظلالاً على الطريق.

## الأداء
- **تجميع الطريق** (`ROADBATCH` في `js/game.js`): كل أجزاء الطريق المتشابهة في كل المقاطع (أسفلت، أرصفة، حواجز، شجيرات، أعمدة إنارة...)
  تُرسم كمجسم واحد لكل خامة بدل ~20 مجسم لكل مقطع؛ عند إعادة تدوير مقطع يُحدَّث جزؤه فقط. نفس الشكل تماماً.
- **مستويات تفاصيل لسيارات المرور** (`TRAFFIC_LODS`): نسخ أخف من كل موديل ثقيل تُستخدم فقط من المسافة التي تصبح فيها
  التفاصيل المحذوفة أصغر من بكسل واحد على الشاشة، وفي البعيد جداً تُرسم السيارة كمجسم واحد بألوانها وإضاءتها وانعكاساتها.
- إصلاح دمج مجسمات سيارات المرور (كان لا يعمل إطلاقاً بسبب شرط خاطئ).

## السماء والمباني
- `js/sky-plus.js`: السماء محسوبة بشيدر (تدرج أزرق، توهج حول الشمس، قرص شمس HDR، أفق يندمج مع الضباب)، وطبقة غيوم
  على ارتفاع 1.8 كم بظلال ذاتية وحواف فضية تتحرك مع الرياح ومع حركة السيارة. ليلاً: قمر فوق البحر، درب التبانة،
  ~5000 نجمة متلألئة، وتوهج أضواء المدينة. شريط «عدد السحب» في الإعدادات يتحكم في كثافة الغيوم.
- `js/city-plus.js`: خلف كل نافذة غرفة حقيقية بعمق (جدران، أرضية، سقف، أثاث، ستائر) تتغير مع زاوية النظر،
  مضاءة ليلاً أو مظلمة، وبعض الغرف فيها وهج تلفاز. النوافذ صارت على الواجهة والجانبين.
